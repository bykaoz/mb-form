# MB Veranda – Opleverformulier montage

Montaj teslim formu (`opleverformulier.html`). Claude Artifact olarak yayınlanır; kayıtlar, imza, fotoğraflar ve PDF
artifact'in bulut deposunda (db + assets) saklanır.

- Müşteri adı ve adresi, fotoğraflar, dijital imza
- Kaydedince A4 PDF üretilir (logo, şirket bilgileri, imza, fotoğraf sayfaları) ve buluta yüklenir
- Arayüz NL / TR; PDF her zaman Hollandaca
- Dosya, Artifact'in sayfa gövdesidir (`<html>/<head>` sarmalayıcısı yayın sırasında eklenir)

Logo ve şirket bilgileri mbveranda.nl sitesinin herkese açık sayfalarından alınmıştır.
